Three engines, one studio

            
Kokoro-82M speaks English with 30 voices. MMS-TTS is the default Bangla speaker; Indic Tiny adds a fixed male and female Bangla voice. Mixed text is split by script, synthesized in order, loudness-matched, and stitched into one stream.

            
Streaming by design

            
Audio starts as soon as the first sentence is ready. Synthesis runs on a worker thread; the interface only ever consumes events, so it never freezes.

            
Private by default

            
Nothing leaves your computer. Models download once into the cache and every later run works with the network off.
